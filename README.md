# SQL Learning Documentation — Microsoft SQL Server

A structured collection of SQL Server scripts covering fundamental to advanced SQL concepts, with practical examples and scenario-based queries.

This repository serves as a personal SQL reference for learning database operations, writing queries, understanding relational database concepts, and preparing for SQL-related technical interviews.

## 📚 Topics Covered

### 1. Database and Table Management
- Creating and dropping databases
- Creating and dropping tables
- Inserting, updating, and deleting records
- SELECT statements and SELECT INTO
- ALTER TABLE operations
- Schemas and variables

### 2. Filtering, Sorting, and Data Retrieval
- DISTINCT and unique values
- ORDER BY and custom sorting
- WHERE conditions and wildcard filtering
- TOP and OFFSET
- IF-ELSE and WHILE loops

### 3. Data Types and Constraints
- Integer and approximate numeric data types
- Date and time data types
- String data types
- Uniqueidentifier and BIT
- Data type conversion
- PRIMARY KEY and FOREIGN KEY
- NOT NULL, UNIQUE, CHECK, and DEFAULT constraints
- Auto-incrementing identity columns

### 4. Aggregate and String Functions
- Aggregate functions
- GROUP BY and HAVING
- ROLLUP and CUBE
- String functions
- Date and time functions
- IIF and CASE expressions
- COALESCE
- Combining names and extracting first and last names

### 5. SQL Joins and Data Modeling
- Introduction to joins
- Joining multiple tables
- Expressions in joins
- Outer joins
- Self joins
- Fact and dimension tables

### 6. Set Operators
- UNION and UNION ALL
- INTERSECT
- EXCEPT

### 7. Subqueries
- Basic subqueries
- IN and NOT IN
- Subqueries in UPDATE statements
- Derived tables
- EXISTS and correlated subqueries
- Scenario-based subquery problems

### 8. Window Functions
- ROW_NUMBER()
- RANK() and DENSE_RANK()
- LAG() and LEAD()
- FIRST_VALUE() and LAST_VALUE()

### 9. Advanced Querying
- Common Table Expressions (CTEs)
- Temporary tables
- PIVOT and UNPIVOT
- MERGE statements
- OUTPUT clause
- Converting tables to JSON
- Creating nested JSON output

### 10. Database Objects and Performance
- Views
- Stored procedures
- Clustered indexes
- Nonclustered indexes
- Slowly Changing Dimensions (SCD)

## 🛠️ Technologies

- Microsoft SQL Server

## 📁 Repository Structure

The repository contains individual `.sql` files organized by topic and numbered for a learning sequence. Supporting images are included for selected data type topics.

## 🎯 Learning Objectives

- Understand SQL Server fundamentals and database operations.
- Write queries to retrieve, filter, transform, and analyze data.
- Work with joins, subqueries, aggregate functions, and window functions.
- Understand constraints, database objects, and indexing.
- Practice scenario-based SQL problems.
- Build a foundation for SQL interviews and data-related roles.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `.sql` files in SQL Server Management Studio (SSMS) or another compatible SQL Server editor.
3. Connect to a SQL Server instance.
4. Review each topic and execute the queries in a test database.
5. Practice modifying the examples and solving the scenario-based exercises.

**Note:** Some scripts create or delete databases, tables, or records. Review each script and use a test environment before executing it.
